## Ideia 1: Rustic Modernism

**Design Movement**: Rustic Modernism - fusão de elementos naturais com geometria limpa e contemporânea

**Core Principles**:
- Texturas orgânicas contrastando com formas geométricas precisas
- Paleta terrosa com acentos vibrantes estratégicos
- Assimetria intencional que guia o olhar
- Autenticidade através de imperfeições controladas

**Color Philosophy**: 
Baseado na paleta do logo, utilizaremos o laranja (#FF8C00) como cor de energia e call-to-action, marrom terroso (#8B4513) como âncora de confiabilidade, verde grama (#4CAF50) para frescor e vitalidade. O objetivo emocional é transmitir confiança rural com sofisticação urbana.

**Layout Paradigm**: 
Layout diagonal assimétrico com seções que se sobrepõem em ângulos de 3-5 graus. Hero section com divisão diagonal 60/40, alternando entre blocos de conteúdo inclinados e retos para criar ritmo visual dinâmico.

**Signature Elements**:
- Divisores SVG com formas orgânicas (ondas, colinas) entre seções
- Texturas de madeira e grama sutis em backgrounds com overlay de gradiente
- Cards de produtos/serviços com cantos arredondados irregulares (border-radius variável)

**Interaction Philosophy**: 
Interações que evocam movimento natural - hover effects que "crescem" como plantas, transições que fluem como água, micro-animações que simulam movimento de animais (tail wag, ear twitch).

**Animation**:
- Parallax suave em backgrounds texturizados
- Fade-in com slide diagonal (não vertical/horizontal padrão)
- Hover: scale + rotate leve (2-3 graus) para simular movimento orgânico
- Loading states com animações inspiradas em natureza (folhas caindo, pegadas)

**Typography System**:
- Display: "Fredoka" (Google Fonts) - arredondada e amigável para títulos principais
- Body: "Outfit" (Google Fonts) - moderna e legível, weights 300-600
- Hierarquia: Display bold para hero (700), Medium (500) para subtítulos, Regular (400) para corpo

## Ideia 2: Playful Brutalism

**Design Movement**: Brutalism Lúdico - estruturas ousadas e brutas suavizadas por elementos divertidos e coloridos

**Core Principles**:
- Tipografia oversized e impactante
- Blocos de cor sólidos e contrastantes sem gradientes
- Grid quebrado intencionalmente com elementos que "escapam"
- Honestidade visual - sem sombras falsas, apenas depth real através de layers

**Color Philosophy**:
Usar as cores do logo em blocos sólidos de alto contraste. Laranja (#FF8C00) como cor dominante agressiva, preto (#000000) para estrutura e texto, verde (#4CAF50) como accent inesperado. Sem gradientes - apenas cores flat com overlays de transparência para criar profundidade.

**Layout Paradigm**:
Grid modular quebrado - seções em blocos retangulares de tamanhos irregulares que se encaixam como Tetris. Hero section com texto gigante que "vaza" para fora do container, imagens que se sobrepõem às bordas das seções.

**Signature Elements**:
- Borders grossas (8-12px) em preto ao redor de cards e seções
- Botões com efeito "pressed" (inset shadow) ao invés de elevação
- Tipografia que quebra as margens e invade outras seções
- Ícones geométricos simplificados em estilo line-art grosso

**Interaction Philosophy**:
Interações diretas e sem sutileza - cliques que causam "impact" visual (shake, punch), hovers que mudam cores drasticamente, transições rápidas e decisivas (100-200ms) sem easing suave.

**Animation**:
- Sem easing curves - apenas linear ou steps() para movimento robótico
- Hover: mudança instantânea de cor + border shift
- Scroll: elementos que "snap" into view ao invés de fade suave
- Micro-interactions com bounce exagerado (cubic-bezier(0.68, -0.55, 0.265, 1.55))

**Typography System**:
- Display: "Space Grotesk" (Google Fonts) - geométrica e bold para impacto
- Body: "DM Sans" (Google Fonts) - clean e funcional, weights 400-700
- Hierarquia: Extra bold (800) para hero, Bold (700) para headings, Regular (400) para corpo
- Letter-spacing apertado (-0.02em) para densidade visual

## Ideia 3: Organic Maximalism

**Design Movement**: Maximalismo Orgânico - abundância visual controlada com inspiração na natureza exuberante

**Core Principles**:
- Layering complexo com profundidade através de múltiplos planos
- Ornamentação intencional sem poluição visual
- Curvas fluidas e formas biomórficas
- Riqueza visual através de padrões, texturas e detalhes

**Color Philosophy**:
Paleta expandida a partir do logo: laranja (#FF8C00) como energia solar, verde (#4CAF50) em múltiplas tonalidades (claro/escuro) para vegetação exuberante, marrom (#8B4513) como terra rica, com adição de dourado (#DAA520) para luxo sutil. Gradientes complexos com 3-4 stops para simular luz natural.

**Layout Paradigm**:
Layout fluido com seções que fluem como água - sem linhas retas horizontais. Hero section com forma de "onda" criada por clip-path, seções subsequentes com bordas curvas que se encaixam perfeitamente. Conteúdo em grids assimétricos com elementos decorativos preenchendo espaços negativos.

**Signature Elements**:
- Ilustrações decorativas de plantas, patas, ossos como elementos de fundo
- Borders com padrões (dashed, dotted) em vez de sólidas
- Cards com múltiplas camadas de sombra (3-4 níveis) para depth extremo
- Padrões SVG sutis (dots, lines, organic shapes) em backgrounds

**Interaction Philosophy**:
Interações ricas e recompensadoras - cada hover revela uma camada adicional de detalhe, transições longas (400-600ms) com easing suave para criar sensação de luxo, feedback visual abundante (múltiplos elementos respondem a uma ação).

**Animation**:
- Parallax em múltiplas camadas (foreground, midground, background)
- Hover: lift com múltiplas sombras + scale suave + brilho adicional
- Scroll-triggered animations com stagger (elementos aparecem em sequência)
- Elementos decorativos com animação idle contínua (float, rotate lento)
- Transições com spring physics para movimento natural

**Typography System**:
- Display: "Playfair Display" (Google Fonts) - serifada elegante para títulos
- Accent: "Lobster" (Google Fonts) - script para destaques especiais
- Body: "Lato" (Google Fonts) - sans-serif humanista, weights 300-700
- Hierarquia: Display bold (700) para hero, Regular (400) para subtítulos com accent font, Light (300) para corpo
- Uso generoso de text-shadow e decorações tipográficas
</text>
